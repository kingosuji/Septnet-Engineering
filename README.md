# SEPTNET Engineering Inc. — Corporate Website

Static React + TypeScript + Vite + Tailwind site for Cloudflare Pages.

## Quick start

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Output: `dist/`

## Docs

- `HANDOFF.md` — master plan + current status for next developer/agent
- `DEPLOYMENT.md` — Cloudflare Pages settings
- `CLIENT_CONTENT_REQUIRED.md` — assets/copy still needed from client
- `CLIENT_REVIEW_CHECKLIST.md` — share with client for homepage/site review

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Lucide React
